# More malloc, free

## 📌 Project Overview

This project is part of the **Holberton School Low-Level Programming** curriculum.

The main objective of this project is to deepen the understanding of **dynamic memory allocation** in C, including how memory is allocated, managed, resized, and released safely.

Throughout this project, I practiced writing clean, efficient, and Betty-compliant code while strengthening my understanding of pointers, memory management, and error handling.

---

## 🎯 Learning Objectives

By completing this project, I learned how to:

- Allocate memory dynamically using `malloc()`.
- Release allocated memory using `free()`.
- Terminate a program using `exit()`.
- Understand the purpose of `calloc()` and `realloc()`.
- Handle memory allocation failures safely.
- Prevent memory leaks.
- Work with one-dimensional and two-dimensional dynamic arrays.
- Follow Betty coding style and Holberton coding standards.
