# Structures, Typedef

## 📌 Project Overview

This project is part of the **Holberton School Low-Level Programming** curriculum.

The objective of this project is to understand how **structures** and **typedef** work in C, how to group related data into a single type, and how to write cleaner and more maintainable code using custom data types.

Throughout this project, I practiced defining structures, using pointers with structures, dynamically allocating memory for structures, and following Betty coding standards.

---

## 🎯 Learning Objectives

By completing this project, I learned how to:

- Define and use structures in C.
- Access structure members using `.` and `->`.
- Create aliases using `typedef`.
- Pass structures to functions.
- Work with pointers to structures.
- Allocate and free memory for structures.
- Write clean, modular, and Betty-compliant code.
